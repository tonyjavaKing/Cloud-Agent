# 演示脚本

启动：

```bash
cp .env.example .env
docker compose up --build
```

打开 `http://localhost:3000`，按下面顺序演示即可覆盖题目要求。

## 1. 代码开发任务

1. 点击“新建会话”，输入：`创建一个 Java Hello World 工具，并写一份 README 说明如何运行。`
2. 展示右侧“执行进度”从执行中变为已完成。
3. 展示助手的流式输出和右侧成果文件，点击文件下载。
4. 在同一会话继续输入：`给这个工具增加一个 --name 参数，并更新 README。`，说明可以继续推进。

## 2. 日常工作任务

1. 新建第二个会话，上传一份 CSV 或 Markdown 材料。
2. 输入：`分析上传材料，输出一份带结论和待办事项的摘要报告。`
3. 展示上传材料只出现在第二个会话的工作目录，成果文件也只出现在该会话。
4. 切换回第一个会话，确认代码任务的消息和成果仍然保留。

## 3. 验证证据

```bash
curl http://localhost:3000/api/health
curl http://localhost:3000/api/sessions
```

页面截图应包含：会话列表、流式助手消息、执行进度、成果文件和下载入口。公开仓库中不提交 `.env`、API Key 或 CLI 登录缓存。
